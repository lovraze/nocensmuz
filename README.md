# NoCensMuz

Стартовый фронтенд музыкальной платформы на React + Vite.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Что уже работает

- адаптивный интерфейс каталога;
- поиск по названию, исполнителю и жанру;
- фильтры жанров;
- избранное в рамках текущей сессии;
- загрузка локальных аудиофайлов и воспроизведение через браузер.

## Важно

Сейчас это клиентский прототип. Загруженные аудиофайлы не отправляются на сервер и не становятся доступны другим посетителям. Для настоящей публичной платформы понадобятся backend, база данных, объектное хранилище для аудио, авторизация, модерация и правила лицензирования/авторских прав.
